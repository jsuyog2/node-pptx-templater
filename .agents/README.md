# Antigravity Agent Configuration — node-pptx-templater

This directory contains project-specific instructions for AI-assisted development of `node-pptx-templater`.

## How to use
1. Copy the `.agent/` directory into the repository root.
2. Open the repository root in Antigravity.
3. Start with the `audit-codebase` workflow when first using these instructions.
4. For subsequent work, describe the feature, bug, refactor, or review you want completed. The rules are intended to apply to all project work.

## Configuration map
- `rules/00-project-mandate.md` — authority, project identity, and non-negotiable principles.
- `rules/10-architecture-and-code-style.md` — architecture and implementation guidance.
- `rules/20-openxml-integrity.md` — PPTX/ZIP/XML invariants.
- `rules/30-feature-catalog.md` — target capability inventory and verification policy.
- `rules/40-testing-and-docs.md` — testing, documentation, and completion requirements.
- `workflows/audit-codebase.md` — initial repository audit.
- `workflows/implement-feature.md` — end-to-end feature development.
- `workflows/bugfix-and-refactor.md` — diagnosis, fixes, and refactoring.
- `workflows/release-readiness.md` — release validation.

These files are working instructions, not a substitute for inspecting the actual source code. The source, tests, package metadata, changelog, and published API are the authority for what currently exists.
