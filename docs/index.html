Overview & Quickstart

node-pptx-templater is an enterprise-grade, spatial-aware OpenXML PowerPoint templating, manipulation, and layout engine for Node.js. It operates with zero external binary dependencies and performs pure non-blocking in-memory transformations. 

npm install node-pptx-templater

Quick Start Example

import { PPTXTemplater } from 'node-pptx-templater'

async function generatePresentation() {
  // 1. Ingest template asynchronously into in-memory Virtual File System
  const ppt = await PPTXTemplater.load('./templates/quarterly-report.pptx')

  // 2. Select slide and replace placeholders across fragmented text runs
  ppt.useSlide(1)
     .replaceText({
       '{{QUARTER}}': 'Q3 2026',
       '{{COMPANY}}': 'Acme Global Enterprise',
       '{{AUTHOR}}': 'Executive Office'
     })

  // 3. Save to output using canonical Export Adapter
  await ppt.toFile('./dist/report-Q3.pptx')
  console.log('✓ Report generated cleanly!')
}

Multi-Format Ingestion Engine

The PackageLoader engine supports 3 distinct input formats seamlessly without requiring pre-conversion:

1. Direct PPTX

Supports direct file paths, Node.js Buffer, and stream.Readable streams (e.g. S3 downloads, HTTP uploads).

2. ZIP Archives

Validates PKZip signatures (0x50 0x4B 0x03 0x04) regardless of file extensions (.zip, .pptx, .tmp).

3. Unpacked XML Folders

Loads extracted OpenXML folder trees directly into the Virtual File System without intermediate compression overhead.

// Load directly from an uncompressed folder tree:
const pptFromFolder = await PPTXTemplater.load('./unpacked-template-folder/')

// Load from streaming byte source:
const pptFromStream = await PackageLoader.load(s3ReadStream)

Core Architecture

Mandate: Zero Synchronous / Blocking I/O

Every transformation operates against an in-memory VirtualFileSystem (Map<string, Uint8Array>). File operations never block the Node.js event loop.

Strict OpenXML AST Normalizer

PowerPoint fragments placeholder tokens across distinct <a:r> runs and <a:t> text nodes during editing (e.g., <a:t>{{</a:t><a:t>user</a:t><a:t>}}</a:t>). Naive regex replacements corrupt XML or miss tokens.

node-pptx-templater employs an AST run normalizer that merges adjacent text runs inside paragraph nodes (<a:p>) before token matching while strictly preserving formatting, fonts, colors, and OpenXML namespaces (p:, a:, r:, c:, w:).

Relationship (.rels) Isolation

When duplicating slides, naive engines reuse existing rId relationship keys, leading to slide corruption or PowerPoint repair alerts. SlideManager.duplicateSlide() generates isolated relationship files (slideX.xml.rels) and fresh unique rId keys for every duplicated element.

Deep Dive Guides

1. Precise Spatial Units (English Metric Units - EMUs)

OpenXML DrawingML uses integer English Metric Units (EMUs) for all spatial coordinates and dimensions. Float coordinates lead to rendering anomalies.

Unit EMU Equivalent Helper Function
1 point (pt) 12,700 EMUs ptToEmu(12) // 152,400
1 inch (in) 914,400 EMUs inToEmu(1.5) // 1,371,600
1 pixel (px @ 96 DPI) 9,525 EMUs pxToEmu(100) // 952,500 
import { toEmu, getBounds, setBounds } from 'node-pptx-templater'

// toEmu accepts string formats or numbers automatically:
const x = toEmu('1.5in')  // 1,371,600 EMUs
const y = toEmu('24pt')   // 304,800 EMUs
const w = toEmu('300px')  // 2,857,500 EMUs

2. Flagship Table Auto-Pagination Engine

When dynamic database rows are added to a table, the rows can exceed the slide's physical canvas. splitTableOnOverflow dynamically estimates row heights and splits content across cloned slides.

Slide Vertical Threshold:
Y_limit = SlideHeight - BottomMargin

When table height exceeds Y_limit:

  1. Calculates row heights dynamically using font size, line count, cell padding, and column width.
  2. Slices rows at the last fitting position on the host slide.
  3. Deep-clones the host slide (preserving layout, master background, and persistent shapes).
  4. Generates isolated relationship files (slideX.xml.rels) and fresh rId keys.
  5. Repeats table headers on the cloned slide and populates remaining rows recursively.
const ppt = await PPTXTemplater.load('template.pptx')
ppt.useSlide(1)

// Populate dynamic table data:
for (const item of auditRecords) {
  ppt.addTableRow('AuditGrid', [item.id, item.name, item.status, item.timestamp])
}

// Automatically paginate if rows breach bottom margin:
const { splitCount, slidesCreated } = await ppt.splitTableOnOverflow('AuditGrid', {
  bottomMargin: '1in',    // or 914400 EMUs
  repeatHeaders: 1         // duplicate table header row on cloned slides
})

console.log(`Created ${slidesCreated} additional slides to fit content.`)

3. Chart Workbook Cache Synchronization

When modifying categories, series, or values in <c:chartSpace>, PowerPoint will display a repair warning unless the embedded Excel binary cache inside ppt/embeddings/Microsoft_Excel_Worksheet*.xlsx is synchronized.

ChartManager and ChartWorkbookUpdater automatically update the chart XML formulas, series cache, AND the embedded Excel worksheet binary simultaneously. 

await ppt.useSlide(2).updateChart('RevenueChart', {
  categories: ['Q1', 'Q2', 'Q3', 'Q4'],
  series: [
    { name: 'North America', values: [120, 145, 180, 210] },
    { name: 'EMEA', values: [95, 110, 135, 160] }
  ]
})

4. Multi-Target Export Adapters

Export presentations to 6 standard targets without third-party converters:

// 1. File output
await ppt.toFile('./output.pptx')

// 2. Node.js Readable Stream
const stream = await ppt.toStream()

// 3. Node.js Buffer
const buffer = await ppt.toBuffer()

// 4. Standard ArrayBuffer (Edge / Web Worker compatible)
const arrayBuffer = await ppt.toArrayBuffer()

// 5. Base64 string with optional Data URI prefix
const dataUri = await ppt.toBase64({ dataUri: true })

// 6. Express HTTP Response (attaches headers and streams presentation)
await ppt.toExpress(res, 'Generated_Deck.pptx')

API Reference

Class

PPTXTemplater

Main fluent orchestrator facade for presentation loading, slide selection, elements mutation, and serialization.

static load(source, options?): Promise<PPTXTemplater>

Loads a presentation from file path, Buffer, Readable stream, or raw uncompressed folder.

useSlide(slideNumber: number): this

Sets active slide context (1-indexed) for subsequent operations.

replaceText(replacements: Record<string, string | number>): this

Replaces placeholder tokens across all text runs with XML entity escaping.

splitTableOnOverflow(tableName: string, options?: SplitOptions): Promise<{ splitCount, slidesCreated }>

Recursively calculates row overflow against slide height limit and paginates table across cloned slides.

toFile(outputPath: string, options?): Promise<void>

Saves the presentation directly to a file asynchronously.

Class

PackageLoader

Ingests OpenXML packages across Buffers, streams, ZIP archives, and raw XML directory trees into an in-memory VirtualFileSystem.

static load(source: PackageSource): Promise<VirtualFileSystem>

isPkZip(buf: Uint8Array | Buffer): boolean

Class

VirtualFileSystem

In-memory file store managing all OpenXML parts as Map<string, Uint8Array> entries with zero synchronous disk I/O.

get(path: string): Uint8Array | undefined

set(path: string, data: Uint8Array | Buffer): void

getText(path: string): string | undefined

setText(path: string, text: string): void

Class

TableManager

Manages <a:tbl> DrawingML tables: cell CRUD, styling, nested cell shapes, and row height estimation.

Class

ChartManager

Handles <c:chartSpace> charts and embedded Excel cache synchronization.

Module

Spatial Units & Bounding Box (src/spatial/units)

Utilities for integer EMU math and element bounding box geometry.

toEmu(value: string | number): number

Converts pt, in, px, emu to integer EMUs.

getBounds(element: any): BoundingBox

Extracts { x, y, width, height } in EMUs from shape transform nodes.

setBounds(element: any, bounds: Partial<BoundingBox>): void

Writes updated integer EMU offsets and extents to XML transform nodes.

checkCollision(boxA: BoundingBox, boxB: BoundingBox): boolean

AABB intersection test between two elements.

Module

Error Classes

  • PPTXError — Base class for all engine errors.
  • SlideNotFoundError — Thrown when referencing an invalid slide index.
  • ChartNotFoundError — Thrown when chart name or relationship ID is missing.
  • TableNotFoundError — Thrown when target table frame cannot be located.
